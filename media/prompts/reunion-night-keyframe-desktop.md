# reunion-night-keyframe-desktop

为玛卡小镇网站生成一张 16:9 横版电影级 3D 微缩玩具夜景关键帧。完整保留圆形玩具小镇的核心识别：左侧钟楼、上方中央蓝顶市政厅、右侧橙顶小屋、右下风车、中央圆形喷泉、蜿蜒水道、树木与路灯。固定为略微俯视的三分之四远景，整座小镇像收藏级桌面模型，材质细腻，建筑结构稳定，不要变成真实城市。

时间是深夜。天空为深靛蓝与午夜蓝，布满克制的星光；大团蓝紫色云雾从小镇建筑之间和画面边缘穿过，形成神秘、柔软、可进入的层次。中央喷泉发出清澈的蓝色微光，沿路只有少量暖金色点状灯火，整体低照度、高级、安静，不要白底，不要白昼，不要强烈霓虹。

小镇里不要出现任何角色、人物、动物或剪影。让 20 到 30 只细小的暖金色萤火虫散布在喷泉、树丛与小路附近，亮点大小自然、疏密不均，像夜色中真实生活着的微小光点；它们不能形成文字或规则图案，也不能抢过小镇和喷泉。

构图上让小镇主体偏中右，画面左侧约四分之一保持较暗、低细节、低对比的云与夜空，供网页标题叠加。画面边缘用柔焦云层自然包围，中心清晰，景深细腻。

不要文字、Logo、水印、边框、界面元素。不要角色、人物、动物、怪物、剪影或巨大黑色轮廓。不要过曝、纯黑死区、恐怖氛围、赛博朋克、真实摄影、建筑融化、重复建筑或漂浮结构。
